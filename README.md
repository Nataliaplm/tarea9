# Análisis de tareas de un sprint

## Descripción
Script en Python para analizar el estado de las tareas de un sprint y evaluar el progreso del equipo de desarrollo.

## Funcionalidades
- Normalización de los estados de las tareas.
- Identificación de tareas sin responsable asignado.
- Cálculo de los puntos totales y completados.
- Cálculo del porcentaje de avance del sprint.
- Análisis de la distribución de la carga de trabajo por responsable.
- Detección de posibles desequilibrios de carga (más del 40%).

## Tecnologías
- Python 3

## Ejecución
Ejecutar el archivo Python desde la terminal:

```bash
python nombre_archivo.py
```
